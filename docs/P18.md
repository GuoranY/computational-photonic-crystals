# P18 — Photonic Crystal Waveguide

Construct and analyze a two-dimensional photonic-crystal waveguide by introducing
a line defect into a square lattice of dielectric rods. Compute the TM projected
band structure of the waveguide supercell using the plane-wave expansion method,
identify guided modes inside the photonic band gap, and reconstruct the corresponding
electromagnetic field distribution.

#### Parameters

- Background refractive index: $n_{\mathrm{bg}} = 1.0$
- Rod refractive index: $n_{\mathrm{rod}} = 3.5$
- Lattice constant: $a = 1.0$
- Rod radius: $r = 0.2a$
- Waveguide supercell: $1 \times 7$ unit cells
- Reciprocal-lattice index limits: $N_x=3$, $N_y=10$
- Number of plane waves: $(2N_x+1)(2N_y+1)=147$
- Number of wavevectors: $41$
- Number of computed bands: $24$

#### Model

A single row of dielectric rods is removed from a square lattice to form a
line-defect waveguide. Periodicity is preserved along the propagation direction
while a finite supercell is used in the transverse direction.

The TM eigenvalue problem is solved with the plane-wave expansion method for
wavevectors along the $\Gamma_{\mathrm{w}}$–$X_{\mathrm{w}}$ direction. Candidate
modes inside the first TM photonic band gap are evaluated using their transverse
field-confinement factor,

```math
C
=
\frac{
\displaystyle
\int_{|y|<a/2}
|E_z|^2\,dA
}{
\displaystyle
\int_{\mathrm{supercell}}
|E_z|^2\,dA
},
```

and the most strongly confined mode is selected as the guided waveguide mode.

The reconstructed field is strongly confined to the line defect while remaining
extended along the propagation direction, demonstrating the existence of a
guided mode supported by the photonic-crystal waveguide.

For the default parameters, the automatically identified TM guided mode has

```math
\frac{\omega a}{2\pi c}
=
0.3687,
\qquad
C
=
0.800,
```

where $C$ denotes the transverse field-confinement factor. Approximately
$80\%$ of the field energy is confined within the waveguide channel, confirming
strong guiding by the line defect.
